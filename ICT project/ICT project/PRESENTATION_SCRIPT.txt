PART 2: KEY FEATURES (Slide 2 - Show gameplay screenshots here)
--------------------------------------------------------------------------------
"The key features of Broken Highway are designed to showcase core CS programming fundamentals:
1. First, we have the 'Juice Engine'. The game actively tracks how long the car is in the air. When you land from a massive jump, the engine mathematically maps that air-time to generate custom particle sparks, skid marks, and an exponential camera screen-shake.
2. Second, we have a 7-Layer Parallax Background. As the car drives, the close trees move fast, the distant buildings move slow, and the sunset sky remains static. This creates true 3D depth.
3. Third, dynamic scaling. As your score gets higher, the game hits velocity spikes, making the car travel faster and forcing the player to react quicker, requiring precise 'double jumps'."

PART 3: GAME LOGIC & HOW IT WORKS (Slide 3 - Show the RAPTOR flowchart)
--------------------------------------------------------------------------------
"So, how does it actually work under the hood? The engine relies on three major concepts:

1. THE EVENT LOOP (The Kernel):
Instead of typical software that pauses and waits for user input, this game runs a continuous non-blocking hardware loop natively in the background. It wipes the screen and redraws every single item 60 times a second using a timer interrupt. This is the 'heartbeat' of the engine.

2. AABB COLLISION MATHEMATICS:
How do we know if the car fell into a gap? We use AABB, which stands for Axis-Aligned Bounding Box collision. We define an invisible rectangle around the car and the gaps. If their X and Y coordinate domains intersect, the program drops an 'Is Alive' boolean to False and triggers the Game Over state.

3. KINEMATICS & GRAVITY:
Gravity in this game isn't a complex physics engine—it's simply integer addition! The car has a Y-Velocity variable. Every single frame, gravity is added to that velocity, pulling the car down pixel by pixel. When you press the SPACE bar, we instantly set the vertical velocity to a negative number, pushing the car up against the pull of gravity!"
